## 目录结构

- `app.py`：本地 Flask 后端，包含注册登录、上传、生成任务、图库、后台、客服、隐私删除、下载等接口。
- `templates/`：所有本地 Flask 页面 UI，包括首页、登录注册、上传、风格选择、确认生成、生成中、结果页、图库、资产、设置、隐私、后台等。
- `static/`：本地页面用到的 CSS、JS、图片素材。
- `docs/`：提示词、水印、生图能力和迁移审计说明。
- `cloudflare-worker/`：Cloudflare Workers 上线版本代码，包含 Worker 后端、静态页面副本、D1/R2 配置和 Wrangler 部署配置。
- `private_media/`：本地私有上传和生成文件目录，当前只保留空目录。

## 环境变量

本地运行前如需调用豆包，请从 `.env.example` 复制一份：

```bash
cp .env.example .env
```

然后填入你的豆包/火山方舟 API Key。不要把 `.env` 上传公开仓库。

Cloudflare Worker 部署时，进入 `cloudflare-worker/` 后用 Wrangler 配置 secrets，不要把 `.dev.vars` 上传公开仓库。
