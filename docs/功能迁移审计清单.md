## 6. 没有移动或不建议移动的内容

没有移动 `node_modules/`：

```text
node_modules/
```

原因：这是依赖安装产物，不是功能源代码。Worker 版用下面命令恢复：

```bash
cd cloudflare-worker
npm install
```

没有移动 `.git/`：

```text
.git/
```

原因：这是原仓库历史，不是运行功能。需要版本历史时应单独复制整个 Git 仓库。

没有移动 `awesome-design-md_副本/`：

```text
awesome-design-md_副本/
```

原因：这是大量外部设计参考资料，不直接参与当前网站运行。若你希望连参考资料也归档，可以再整体复制。

## 7. 仍需要外部配置的能力

本地 Flask 版：

```text
.env 里需要 DOUBAO_API_KEY
```

Cloudflare Worker 线上版：

```text
需要 wrangler secret 配置 DOUBAO_API_KEY 或 ARK_API_KEY
需要真实 D1 database_id
需要真实 R2 bucket
微信支付正式环境需要商户号、证书、回调等 secret
```

这些不是普通文件移动能完全解决的，部署环境必须重新配置。

## 8. 本地 Worker 联调配置

已安装 `cloudflare-worker/node_modules/`，可直接在 Worker 子目录运行：

```bash
npm run dev
```

当前 `.dev.vars` 已配置为本地联调模式：

```text
ENVIRONMENT=development
INITIAL_CREDITS=1000
```

因此本地 `wrangler dev` 会开启微信支付 mock，并给新用户 1000 初始积分。
